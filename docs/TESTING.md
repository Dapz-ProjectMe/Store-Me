- [ ] Home page loads
- [ ] Service cards render from `SERVICES`
- [ ] Service detail dialog opens and closes
- [ ] Checkout receives selected service ID
- [ ] Missing/invalid service ID is handled

- [ ] Mobile navigation opens and closes
